Avisa+  ( Sistema inteligente de alertas focado em populações de áreas vulneráveis )

É um sistema inteligente de alertas focado em populações de áreas vulneráveis com pouca ou nenhuma conectividade. 
Ele garante que a comunidade seja notificada imediatamente sobre falhas em serviços essenciais, como falta de água, energia ou problemas no transporte.
